PORTAL 360º VR — INSTALAÇÃO COMPLETA NO NOVO REPOSITÓRIO

Destino: newpceducador-hue/portal-360-
Branch: main | GitHub Pages: pasta / (root)

Este pacote reúne o hub atualizado e os arquivos das experiências.
O envio anterior separou arquivos da pasta hub/ e não incluiu todos
os conteúdos. Agora é essencial preservar a estrutura das pastas.

1. No Windows, clique no ZIP com o botão direito e escolha
   “Extrair Tudo”. Não arraste arquivos avulsos de dentro do ZIP.

2. No GitHub Desktop, entre na conta que pode editar o repositório
   newpceducador-hue/portal-360- e clone ESSE repositório.
   Não altere o repositório original Newpc-Alan/portal-360-vr.

3. Abra a pasta clonada usando Repository > Show in Explorer.
   Copie para ela TODO o conteúdo extraído, substituindo os arquivos
   com o mesmo nome. Copie os diretórios completos, sem retirar os
   arquivos de dentro deles e sem criar uma pasta extra envolvendo
   todo o portal.

4. Confira a raiz antes de publicar. Ela deve conter, entre outros:

   index.html
   diagnostico-vr.html
   .nojekyll
   hub/
   apps/
   assets/
   sala/

   Exemplo: catalogo.js deve ficar em hub/catalogo.js, e as
   experiências devem continuar dentro de apps/. Não coloque
   esses arquivos soltos junto de index.html.

5. Este pacote não usa domínio personalizado. Se existir um arquivo
   CNAME na raiz deste NOVO repositório, remova-o. Em Settings >
   Pages, deixe Custom domain vazio. Isso não altera o domínio
   nem a publicação do repositório original.

6. No GitHub Desktop, revise as alterações, escreva uma mensagem
   como “Instalação completa do Portal 360 VR”, clique em
   Commit to main e depois em Push origin.
   Use GitHub Desktop para enviar o conjunto completo: o pacote
   tem mais arquivos do que o limite de um envio pelo navegador.

7. No GitHub, abra Settings > Pages. Selecione publicação a partir
   de uma branch, branch main e pasta / (root). Salve e aguarde
   a publicação concluir.

8. Acesse:
   https://newpceducador-hue.github.io/portal-360-/

   Para ir direto ao catálogo:
   https://newpceducador-hue.github.io/portal-360-/?catalog=1

9. Recarregue a página e confira capas, busca, abertura de cada
   experiência, áudio e retorno ao catálogo. Nos óculos, teste
   também diagnostico-vr.html, a entrada em VR e a saída de cada
   aplicação. A entrega não equivale a homologação em headset físico.

Não teste WebXR abrindo index.html diretamente por file://.
Use o endereço HTTPS publicado acima.
